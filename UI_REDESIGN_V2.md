# UI Redesign v2 - Centered Layout with Blue Hypothesis Box

## Color Scheme Update
- **Primary (Blue):** #4a90e2 - Hypothesis box, save button
- **Accent (Orange/Coral):** #f55e61 - Brand title, add button, edit button
- **Background:** #ffffff (White)
- **Text Primary:** #1a1a1a
- **Text Secondary:** #666666
- **Neutral Gray:** #f8f8f8 (chips), #e8e8e8 (borders)

## Major Layout Changes

### Centered Design
- Max width: 600px
- Content centered on page with `alignSelf: 'center'`
- All text elements centered
- Chips centered with `justifyContent: 'center'`

### Brand Identity
- **Title:** "wohl" (lowercase)
- Font size: 48px
- Color: Orange (#f55e61)
- Letter spacing: -1
- Prominent at top of page

### Section Titles
- Font size: 20px (increased from 18px)
- Centered alignment
- More prominent hierarchy

### Hypothesis Box (Blue Theme)
- Background: #f7faff (light blue)
- Border: 2px solid #4a90e2 (blue)
- Blue shadow effect
- Centered text
- Larger padding (24px)

### Buttons

**Add Button (Orange):**
- Circular: 48x48px
- Orange background (#f55e61)
- "+" symbol
- Orange shadow

**Save Button (Blue):**
- Blue background (#4a90e2)
- "Save & Continue" text
- Blue shadow
- Centered

**Edit Button (Orange Outline):**
- Transparent background
- Orange border (#f55e61)
- Orange text
- Centered

### Activity Chips
- Neutral gray (#f8f8f8)
- Gray border (#e0e0e0)
- Gray "×" remove button (not orange)
- Centered layout

### Typography Updates
- Brand: 48px
- Title: 28px
- Section titles: 20px (centered)
- Body: 17px (hypothesis text)
- Labels: 12px uppercase with letter-spacing

## Visual Hierarchy
1. "wohl" brand (48px, orange)
2. Page title (28px, centered)
3. Hypothesis box (blue, prominent)
4. Section titles (20px, centered)
5. Content (centered, clean)

## Spacing
- Container padding: 32px horizontal, 48px vertical
- Section gaps: 40px
- Element gaps: 16px
- Centered max-width container

## Professional Touches
- Centered, magazine-style layout
- Blue for primary content (hypothesis)
- Orange as accent for brand and actions
- Neutral grays for secondary elements
- Clean, spacious design
- Uppercase labels with letter-spacing
