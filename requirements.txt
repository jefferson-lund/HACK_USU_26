# Wellness Tracker - Requirements

## Project Overview
A React Native wellness tracking app built with Expo that allows users to track daily activities and analyze their correlation with wellness outcomes using multiple linear regression.

## Installation

```bash
npm install
```

## Platform Support
- iOS (via Expo Go or development build)
- Android (via Expo Go or development build)
- Web (with in-memory storage fallback)

## Key Features
1. Daily activity tracking with checkboxes
2. Outcome rating (1-10 scale)
3. SQLite persistence (native) / in-memory storage (web)
4. Multiple linear regression analysis
5. Correlation coefficient visualization (heatmap)
6. Scatter plot (predicted vs actual outcomes)
7. Dummy data generation for testing
8. R² calculation for model fit

## Metro Bundler Configuration
Custom metro.config.js required for:
- Resolving is-any-array package (ml-regression dependency)
- Supporting .mjs file extensions

## Database Schema
- setup: User's wellness goal/outcome
- activities: List of tracked activities
- activity_logs: Daily activity completion (boolean)
- outcome_ratings: Daily outcome ratings (1-10)

## Notes
- Web platform uses in-memory storage (data not persisted on refresh)
- Native platforms use SQLite for persistent storage
- Minimum 10 data points recommended for regression analysis
- Activities with |coefficient| < 0.1 filtered from visualizations
