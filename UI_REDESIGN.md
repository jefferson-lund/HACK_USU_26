# UI Redesign - Main Landing Page

## Color Scheme
- **Primary:** #f55e61 (Orange)
- **Background:** #ffffff (White)
- **Text Primary:** #1a1a1a (Near Black)
- **Text Secondary:** #666666 (Gray)
- **Text Tertiary:** #888888 (Light Gray)
- **Input Background:** #fafafa (Off-White)
- **Input Border:** #f0f0f0 (Light Gray)

## Design Changes

### Typography
- **Title:** 32px, bold, letter-spacing -0.5
- **Subtitle:** 16px, line-height 24px
- **Labels:** 18px, semi-bold
- **Body:** 16px, line-height 24px
- **Helper text:** 14px

### Spacing
- Container padding: 24px horizontal, 40px vertical
- Section gaps: 32px (increased from 24px)
- Element gaps: 12px

### Components

#### Buttons
- Background: #f55e61 (orange)
- Text: White, bold, 16px
- Padding: 20px horizontal, 14px vertical
- Border radius: 12px
- Shadow: Orange glow effect

#### Input Fields
- Background: #fafafa
- Border: 2px solid #f0f0f0
- Border radius: 12px
- Padding: 16px horizontal, 14px vertical
- Font size: 16px

#### Activity Chips
- Background: #fff5f5 (light pink)
- Border: 1px solid #ffe0e0 (pink)
- Border radius: 20px (pill shape)
- Remove button: Orange circle with white X

#### Hypothesis Box
- Background: #fff9f9 (very light pink)
- Border: 2px solid #f55e61 (orange)
- Border radius: 16px
- Padding: 20px
- Subtle orange shadow

### Visual Hierarchy
1. Title (largest, bold, dark)
2. Hypothesis box (orange border, prominent)
3. Section labels (semi-bold, 18px)
4. Input fields (subtle background)
5. Helper text (smaller, gray)

## Professional Touches
- Increased spacing for breathing room
- Subtle shadows on buttons and hypothesis box
- Consistent border radius (12-20px)
- Color-coded feedback (orange for AI, gray for fallback)
- Pill-shaped chips with soft pink background
- Clean white background throughout
